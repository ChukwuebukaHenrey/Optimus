# PIXEL ASSET REQUEST — A-05 Repair Smith (the coding agent)

Status: needs_generation · Priority P0

**Why a separate character:** Optimus's story has three different actors, and the cast should
show it.
- The **browser run** (Kane) acts and records.
- The **Optimus agent** judges.
- The **coding agent** repairs, and is never shown judging.

Giving the repairer its own silhouette makes "the agent repairs, it never judges" visible at a
glance.
